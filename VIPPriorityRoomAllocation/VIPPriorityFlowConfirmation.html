Current Confirmed Flow

Staff submits reservation request
Input: Member ID / IC / Passport, phone number, check-in date, check-out date.
System checks loyalty record
Checks the first input against LoyaltyAndRewardsService/src/member.csv by MemberId.
System creates reservation
Reservation is saved immediately as PENDING, with no room assigned yet.
Reservation enters Binary Max Heap Priority Queue
Every reservation enters the heap, not only when requests are more than rooms.
Staff runs Allocate Available Rooms
System pops reservations from heap by loyalty priority and assigns available Standard Rooms.
System updates result
Room available: CONFIRMED. No room left: REJECTED.
Check-in / check-out
Check-in changes room to OCCUPIED. Check-out changes room to NEEDS_CLEANING.

Priority Rule

Priority Order Loyalty Tier Source
1 PLATINUM Existing Loyalty tier data
2 GOLD Existing Loyalty tier data
3 SILVER Existing Loyalty tier data
4 CLASSIC Default for non-member or unmatched guest

If two guests have the same tier, earlier booking time gets priority.
